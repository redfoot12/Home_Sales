# Module 22 Challenge -- Big Data
## Overview

This challenge demonstrates the use of Apache Spark and PySpark to analyze a real estate dataset using both SparkSQL and the PySpark DataFrame API. Key concepts include:

- Reading data from a remote CSV source
- Creating temporary views
- Querying with SparkSQL
- Caching and un-caching tables
- Writing and reading partitioned Parquet data
- Measuring and comparing query runtimes
